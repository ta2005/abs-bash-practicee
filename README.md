## 🛠️ How to Run These Scripts

1. **Clone the repo:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/abs-bash-practice.git](https://github.com/YOUR_USERNAME/abs-bash-practice.git)
   cd abs-bash-practice
2. **Make a script executable:**
```bash

chmod +x exercise_name.sh```

3. **Execute:**
```bash

./exercise_name.sh [arguments]```
